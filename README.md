# Claude セットアップガイド

非エンジニアが **Claude Code（と Cowork）をゼロから導入**できる、スマホで読めるステップ式ガイドです。

🔗 **公開ページ**: https://icchooo.github.io/claude-setup-guide/

---

## 📱 これは何？

「Claude Code を使ってみたいけど、何から始めればいいか分からない」という方向けに、
**アカウント作成 → 有料プラン加入 → アプリ導入 → 初期設定**までを、画面写真つきで一つずつ案内します。

- **スマホで読みながら、PCで操作する**使い方を想定した縦長デザイン
- **お使いのOS（Windows / Mac）と、使いたい機能（Cowork / Code）を選ぶ**と、その人に必要な手順だけが表示されます
- 進捗バー・チェックリスト・コードのコピーボタンつきで、迷わず最後まで進めます

## 👤 こんな人におすすめ

- これから Claude を触ってみたい非エンジニアの方
- 「ターミナル（黒い画面）は怖い」という方（このガイドは基本アプリ内だけで完結します）
- 家族・知人に Claude Code を勧めたいけど、説明が大変な方（このURLを渡すだけでOK）

## 🗺 ガイドの流れ

1. Claude のアカウントを作る
2. 有料プランに加入する（最低 Pro）
3. Claude デスクトップアプリを入れる
4. アプリを起動してログインする（Chat / Cowork / Code の3タブを理解）
5. **Cowork** を使ってみる（選んだ場合）
6. **Code** の準備（Git のインストール）と使い方（選んだ場合）
7. 最低限やっておきたい初期設定（言語・プライバシーなど6項目）

> 表示される手順は、最初の画面で選んだ **OS × 機能** の組み合わせによって自動で変わります。

## 🛠 技術構成

- HTML / CSS / バニラ JavaScript の **1ファイル完結**（`index.html`）
- 外部サーバーとの通信なし・個人情報の保存なし（ブラウザだけで完結する静的ページ）
- ホスティング: **GitHub Pages**
